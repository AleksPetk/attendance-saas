# Check Station Documentation

Check Station is a multi-tenant check-in and attendance platform. Organizations configure Groups, Members, kiosks, and attendance workflows for their own operations.

This site is the public documentation and legal home for Check Station. The pages published here are served from a single canonical content API so the same documents can later be shown inside the Check Station workspace and native apps.

**Using CheckStation**

- Kiosk Setup — configure, preview, launch, lock, and exit a Group kiosk
- Billing & Plans — plans, prices, upgrades, downgrades, and billing

**Help**

- Support — search CheckStation help, check system status, then contact us if you still need a person

## How to read these documents

These pages describe the **current product**. They do not promise certifications, hosting regions, or legal entity details that have not been designated. Where an item is still unresolved, the document says so instead of inventing a fact.
