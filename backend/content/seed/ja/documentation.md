# Check Station ドキュメント

Check Station は、マルチテナント型のチェックイン・出席管理プラットフォームです。各組織が、自社の運用に合わせてグループ、メンバー、キオスク、出席ワークフローを設定できます。

このサイトは Check Station の公開ドキュメントおよび法務情報の拠点です。ここに公開されるページは、単一の正規コンテンツ API から配信されるため、同じドキュメントを将来的に Check Station ワークスペースやネイティブアプリ内でも表示できます。

## 現在利用可能なコンテンツ

**はじめに**

- CheckStation をはじめる — アカウント作成から最初のチェックイン成功まで

**CheckStation の使い方**

- グループとメンバー — 人物、グループ、ビジター、アーカイブ、プラン制限
- キオスク設定 — グループ所有キオスクの設定、プレビュー、起動、ロック、終了
- 請求とプラン — プラン、価格、アップグレード、ダウングレード、請求

**ヘルプ**

- サポート — CheckStation ヘルプの検索、システム稼働状況の確認、それでも解決しない場合のお問い合わせ
- FAQ — 同じ正規 FAQ API からの検索可能な回答

**法務**

- プライバシーポリシー — Check Station が個人データおよびワークスペースデータをどのように扱うか
- 利用規約 — Check Station の利用を規定する契約

## ドキュメントの読み方

これらのページは**現在の製品**を説明しています。認定、ホスティングリージョン、未確定の法人情報など、確定していない事項を約束するものではありません。未確定の項目については、事実を創作せず、その旨を明記しています。
